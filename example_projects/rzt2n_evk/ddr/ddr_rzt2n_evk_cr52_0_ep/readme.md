# RZT2N EVK Example Projects

This directory contains example projects for the **RZT2N EVK** (R9A07G076, Cortex-R52).

## Available Example Projects

| Project | Core | Description |
|---------|------|-------------|
| [ddr_rzt2n_evk_cr52_0_ep](../ddr_rzt2n_evk_cr52_0_ep/) | CR52_0 | LPDDR4 bring-up via the Address Expander (BSP feature, no driver instance) — memory integrity, runtime mirror remap, cache/DMA coherency, and DDR-as-system-memory checks, 6 runtime-selectable modes |
