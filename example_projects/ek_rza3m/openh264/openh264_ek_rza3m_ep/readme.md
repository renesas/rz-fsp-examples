# OpenH264 Example Project

The OpenH264 project demonstrates H.264 video decoding and real-time display capabilities on the Renesas RZ MPUs using the OpenH264 library and Renesas FSP.

## Available Example Projects

| Project | Description |
|---------|-------------|
| [openh264_ek_rza3m_ep](../openh264_ek_rza3m_ep/) | H.264 video stream decoding using OpenH264 software decoder. MIPI-DSI display output via ILI9881 LCD controller |
